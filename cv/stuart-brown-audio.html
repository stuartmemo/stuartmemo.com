Projects

As a self-confessed web enthusiast, I spend a lot my spare time developing projects as well as participating in the JavaScript community. A selection of these projects can be found below.

  • Stuart Memo — My personal site where I experiment with the latest web technologies, including <canvas>, SVG, and the Web Audio API. I also live code tutorials and post them to YouTube.
  • Beat Petite — A drum machine using Backbone, Web Workers, and the Web Audio API. The individual drum sounds are not samples, they were created from scratch using oscillators, filters and envelopers.
  • Theresa's Sound World — A friendly Web Audio wrapper library for manipulating sound in the browser. Currently a work in progress, I'm using Jasmine and Test-Driven Development to ensure the library is as robust as possible. The library provides various audio helper functions for capturing user audio input, adding effects, and even working with MIDI — Source Code.
  • Sympathetic Synthesizer System Mk 1 — An plug-in free, native HTML5 browser synth. Mimicking old analogue synths, it uses a series of oscillators, manipulated by a variety of handmade envelopes and a touch of LFO. The input elements were styled by accessing the Shadow DOM.
  • Qwerty Hancock — An open-source project to allow developers to add a musical keyboard to their own instruments. Originally developed using SVG with the Raphaël library, it now uses native HTML/JavaScript.
  • JavaScript is the new Punk Rock — My talk from last year's JSConf Eu, where I spoke about using JavaScript to make music, and to not worry about what people may think of the things you make.
  • Raygum — A quick and simple way of creating QR codes. Uses both Google's Maps and Charts API.
  • Github — My Github account, containing the numerous open-source projects I've created and contributed to.
  • All Fridges Are Psychotic — I teamed up with my brother to create an adventure game for iOS. Using Unity3D, we created a "hilarious" puzzle game that rocketed to the top of charts in Lebanon.
