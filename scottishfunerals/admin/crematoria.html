Notes

Entries into this form are validated as strictly as possible in order to reduce the risk of erroneous values being submitted to the database.

The Save Changes button is only enabled when at least one valid new value has been entered and there are no invalid entries.

The Discard Changes button resets all values back to what they were when the page loaded. Moving to another page also discards the changes and does not save.

Saved values will appear in pages which show Crematorium prices (eg Calculators)

Values (or blanks) which are not valid are highlighted in red/pink.

  • Where a column requires an entry in every cell, a blank will be treated as an invalid entry.

Good values (valid to save) are shown in green.

Where the original cell value is re-entered, it will revert to black.

Digits more than two decimal places are ignored and are dropped if the value is saved (eg 600.056 becomes 600.05).

For convenience,

  • decimal places (pennies) are shown only when they are not both zero. You can enter prices with or without .00 pence.
  • clicking in a cell selects the whole value in that cell.
